# spec-analysis: verification

Test cases for automation testers. Start each automated test's name with its `TC` ID.

## Test setup

- Test framework: Vitest with coverage-v8 (vitest.config.ts); tests are colocated *.test.ts files and in test/integration and test/e2e.
- Mutation testing: Stryker (stryker.config.json). Full verification via the npm run verify script (package.json:30).
- Replace the LLM with a FakeLlmProvider returning canned schema-valid data and recording each request (per sdd/specs/spec-analysis/verification.md:5); a TruncatedError simulates truncation.
- Pipeline integration tests: test/integration/pipeline.test.ts; helpers in test/support/helpers.ts.
- Claude CLI replacement: test/fixtures/fake-claude/claude and recorded outputs in test/fixtures/recorded-cli-output/*.jsonl.
- Use temp-folder sample projects (code-only, docs-only, conflicting docs/code, large project) and an in-memory or temp-folder cache.
- Manual tests need a real provider (Claude CLI or Anthropic API) and are judged by criteria, not exact text.
