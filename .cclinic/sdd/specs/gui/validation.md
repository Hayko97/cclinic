# gui: validation

Acceptance criteria from the user's point of view.

| ID | Covers | User need | Accepted when |
|---|---|---|---|
| VAL-GUI-001 | FR-GUI-001, FR-GUI-003, FR-GUI-004, FR-GUI-005, FR-GUI-006, FR-GUI-007 | I can open cclinic's GUI for my project with one command | `cclinic gui` in my project opens the GUI in my browser, prints its link, stops cleanly on Ctrl+C or when I close the terminal, and a second one tells me where the first one is |
| VAL-GUI-002 | FR-GUI-002, FR-GUI-008, FR-GUI-009, FR-GUI-010, FR-GUI-012 | Nobody else, and no website, can use my GUI | Other machines can't reach it, and a request without my link's token, or from another website, gets nothing |
| VAL-GUI-003 | FR-GUI-011, FR-GUI-013 | The GUI never leaks my secrets or runs commands I didn't choose | Secrets in output, logs and transcripts show as redacted, and nothing I type can run a command other than the one I picked |
| VAL-GUI-004 | FR-GUI-014, FR-GUI-015, FR-GUI-016, FR-GUI-017, FR-GUI-018 | I can set up cclinic for my project without the terminal | From Setup I can check, generate with any option, install skills, set up the environment, choose a model and clean, answering the same questions the CLI asks, and I can see how to connect my agent |
| VAL-GUI-005 | FR-GUI-019, FR-GUI-020, FR-GUI-021, FR-GUI-022 | I can see and manage my roadmaps and tasks | I see every roadmap, milestone and task with status and dependencies, I can make every change `cclinic tasks` allows, and changes made elsewhere appear by themselves |
| VAL-GUI-006 | FR-GUI-023, FR-GUI-024, FR-GUI-025, FR-GUI-026 | I can plan a roadmap or a task with the PM agent in the GUI | I answer the PM's questions in forms, approve, refine or cancel its proposal, and only an approved plan is saved |
| VAL-GUI-007 | FR-GUI-027, FR-GUI-028, FR-GUI-029, FR-GUI-030, FR-GUI-031, FR-GUI-032 | I can run a roadmap in auto mode and watch it work | I start a run after seeing its plan, watch each task and agent live with the cost, can stop it safely, and can read past runs' reports and logs |
| VAL-GUI-008 | FR-GUI-033, FR-GUI-034, FR-GUI-035, FR-GUI-036 | I see the output of everything the GUI runs | Each command shows its live output and result, I can cancel it, and the GUI won't start two that clash |
| VAL-GUI-009 | FR-GUI-037, FR-GUI-038 | I can follow each change's steps and answer what's waiting for me | I see each change's step and history, and can answer a waiting gate, while agents can't |
| VAL-GUI-010 | FR-GUI-039, FR-GUI-040, FR-GUI-041, FR-GUI-042, FR-GUI-043, FR-GUI-044 | I can see what Claude did, and is doing, for a task or spec | A task or spec page lists its Claude Code sessions, and opening one shows its conversation updating live, without letting me change it |
| VAL-GUI-011 | FR-GUI-045, FR-GUI-046, FR-GUI-047 | The GUI doesn't make cclinic heavier or messier | Installing cclinic adds no new packages, and the GUI leaves nothing in my project that Git, analysis or `clean` notices |
| VAL-GUI-012 | FR-GUI-048, FR-GUI-049, FR-GUI-055, FR-GUI-064, FR-GUI-065, FR-GUI-066 | The GUI looks clean and modern, and everyone can use it | Every screen looks consistent in light and dark, works by keyboard and with a screen reader, never relies on colour alone, and never shows a blank area while loading |
| VAL-GUI-013 | FR-GUI-050, FR-GUI-051, FR-GUI-063 | I can work fast and learn the CLI as I go | I can reach any action with Ctrl/⌘+K, see the matching `cclinic` command for everything I do, and share or reload any view's link |
| VAL-GUI-014 | FR-GUI-052, FR-GUI-053, FR-GUI-062 | I always know what's waiting for me and what to do next | A Needs you count is always visible and lists everything waiting for me, the canvas suggests my next step, and I'm told when a job finishes |
| VAL-GUI-015 | FR-GUI-054 | I can read the same work as plain text | I can switch between the canvas and a list grouped by roadmap and milestone that always agree, and see each task's dependencies there too |
| VAL-GUI-016 | FR-GUI-056, FR-GUI-057 | I can tell at a glance how a run is going and if an agent is stuck | Each task shows its steps with time and cost, the running step shows what it's doing now, and a quiet agent is flagged |
| VAL-GUI-017 | FR-GUI-058, FR-GUI-059 | I can read live output without it jumping away | Output follows new lines until I scroll up or select text, then waits with a "jump to latest" button, and I can search and filter it |
| VAL-GUI-018 | FR-GUI-060, FR-GUI-061 | Forms are simple and I can't make an expensive mistake by accident | Forms show the common options first, explain bad values before I submit, and costly or destructive actions say exactly what will happen and default to Cancel |
| VAL-GUI-019 | FR-GUI-067, FR-GUI-068, FR-GUI-069, FR-GUI-082 | I can see all my work as one connected picture | Each roadmap is a frame of task cards with title, description, status and spec, and arrows show which tasks wait on which, even across roadmaps |
| VAL-GUI-020 | FR-GUI-070, FR-GUI-071, FR-GUI-077 | I can see which agent works on each task, and read its Claude session in one click | Cards show the agents working now and their sessions, and clicking a card or session shows the live conversation |
| VAL-GUI-021 | FR-GUI-076, FR-GUI-078 | I can see AI and my own work side by side | A roadmap the AI is running and a task I'm working on by hand are each clearly marked at the same time, and I can start or stop AI on a roadmap from its frame |
| VAL-GUI-022 | FR-GUI-072, FR-GUI-073, FR-GUI-074 | I can arrange the canvas my way, and it stays that way | I can pan, zoom, fit and drag cards and frames, my layout is still there after a reload or restart, and new tasks find a sensible place by themselves |
| VAL-GUI-023 | FR-GUI-075, FR-GUI-079, FR-GUI-080, FR-GUI-081 | The canvas stays current, easy to search, and usable for big roadmaps and without a mouse | Changes appear by themselves, I can search, filter and jump to a roadmap, I can do everything by keyboard, and it stays smooth with hundreds of tasks |
